# Runforge - Dashboard запусков AI-агентов

Тестовое задание на позицию Junior Frontend Developer.

## Запуск проекта
1. Установите зависимости:
   ```bash
   npm install
   # или bun install
   ```
2. Запустите локальный сервер:
   ```bash
   npm run dev
   # или bun run dev
   ```

## Тестирование
В проекте настроен Vitest и React Testing Library. Покрыты 3 основных сценария (поиск, фильтрация по статусу, открытие деталей).
Для запуска выполните:
```bash
npm run test
# или bun run test
```

## Структура проекта
- `src/api` — локальный mock-сервис (с задержкой и имитацией ошибок).
- `src/types` — TypeScript интерфейсы.
- `src/App.tsx` — главное состояние (данные, загрузка, ошибки) и логика фильтрации.
- Выделены смысловые компоненты: `Controls` (поиск и фильтры), `RunList` (карточка), `RunDetails` (детализация и логи).
